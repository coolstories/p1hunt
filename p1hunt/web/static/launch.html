Identities

An authorization finding is a comparison between two principals. Without both, a "confirmed IDOR" means nothing — the proof never established that the caller shouldn't have been able to read the thing.

These are passed to the hunt process through its environment only. They never appear in the command line (which ps exposes), and the scope file records the variable name, never the value.
